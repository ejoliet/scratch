## [0.1.0] - 2026-03-29

### Added
- `CLAUDE.md` — project intelligence file with conventions, commands, and skill table.
- `.claude/settings.json` — MCP server config, hooks, and permission allow/deny lists.
- `skills/add-test.md` — `/add-test` slash command skill for generating pytest tests.
- `skills/review.md` — `/review` slash command skill for pre-commit code review.
- `skills/changelog.md` — `/changelog` slash command skill for changelog generation.
- `src/calculator.py` — sample module (`add`, `subtract`, `multiply`, `divide`).
- `src/main.py` — entry point demonstrating the calculator module.
- `src/tests/test_calculator.py` — parametrized pytest suite covering all operations.
